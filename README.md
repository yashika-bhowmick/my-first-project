Learning Log

A Django web application for tracking learning topics and recording learning progress.

**Technologies:** Python, Django, SQLite, HTML, CSS, Bootstrap.

**Features:**
- User registration and login
- Create and view learning topics
- Add entries to topics
- Database management using Django models

**Concepts Practised:**
- Django project and app setup
- Models and database migrations
- URLs, views, and templates
- Template inheritance
- User authentication

Inspired by *Python Crash Course* by Eric Matthes.
